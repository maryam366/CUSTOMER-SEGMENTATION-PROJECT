# 🔬 Professional K-Means Clustering Engine

## 📌 Project Overview

A professional desktop application for **real-time customer segmentation** using **Parallel K-Means Clustering**. This tool features a modern GUI, real-time performance metrics, and interactive visualizations.

### 🎯 Key Features

| Feature | Description |
|---------|-------------|
| **Parallel Processing** | Multi-core CPU support for faster clustering |
| **Real-time Metrics** | Live performance dashboard with speedup analysis |
| **Interactive Visualizations** | Cluster plots, elbow method, and speedup graphs |
| **Synthetic Data Generator** | Configurable dataset with make_blobs |
| **Professional GUI** | Modern dark theme with responsive design |
